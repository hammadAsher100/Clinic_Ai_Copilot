📋 About These Metrics

All models evaluated on held-out test sets using stratified train/test splits. Metrics computed using scikit-learn on predictions from saved model artifacts.

Heart Disease (ANN): UCI Heart Disease dataset (real patient data)
Pneumonia (CNN): Synthetic chest X-ray images
Symptoms (BiLSTM): Symptom2Disease dataset

All visualizations are powered by Plotly and are fully interactive. Hover over data points for details, zoom, pan, and export images as needed.
